# Soham Rane — Developer Portfolio

A personal developer portfolio showcasing my academic background, software development projects, technical skills, and professional experience.

I am pursuing an M.S. in Computer Science at Northeastern University, with interests in software engineering, artificial intelligence, and building practical technology solutions.

---

## Features

- Responsive design for desktop and mobile devices.
- Dark and light theme support.
- Dedicated sections for About, Experience, Projects, Skills, Education, and Contact.
- Project descriptions and technology stacks.
- Resume access and professional profile links.
- Smooth animations and transitions.
- SEO metadata and structured data.

---

## Tech Stack

- **Framework:** Next.js
- **Frontend:** React.js, TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Theme Management:** next-themes
- **Analytics:** Vercel Analytics
- **Tools:** Git, GitHub, npm
- **Deployment:** Vercel

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/johadsalka/Portfolio.git
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open http://localhost:3000 in your browser.

---

## Available Scripts

| Command                 | Description                       |
|-------------------------|-----------------------------------|
| `npm run dev`           | Starts the development server     |
| `npm run build`         | Builds the production application |
| `npm run start`         | Starts the production server      |
| `npm run lint`          | Runs lint checks                  |
| `npm run typecheck`     | Checks TypeScript types           |
| `npm run check:content` | Validates portfolio content       |

---

## Deployment

This portfolio can be deployed using Vercel.

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Select the Next.js framework preset.
4. Deploy the application.

For a production build, run:

```bash
npm run check:content
npm run build
```
